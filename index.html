Automated Network Monitoring & Customer Alert System

n8n Docker PostgreSQL Smart OLT Integration Email Automation

Challenge

Customer network outages (Loss of Signal - LOS) were not being communicated proactively, leading to increased support calls and customer dissatisfaction. The technical team needed real-time visibility into which customers were affected to prioritize troubleshooting efforts.

Solution

Built an automated monitoring system that continuously checks customer ONU (Optical Network Unit) status from Smart OLT data and proactively notifies both customers and internal teams when network issues are detected.

Technical Implementation

  • Deployed using Docker on Ubuntu server with scheduled execution every 7 hours
  • Connected to PostgreSQL database with two tables: network information and customer data
  • Integrated with Smart OLT system to retrieve real-time ONU status data
  • Implemented conditional logic to detect LOS (Loss of Signal) status changes
  • Automated customer email notifications acknowledging the issue and ticket creation
  • Generated consolidated reports for internal technical team with affected customer lists
  • Key n8n nodes: Schedule Trigger, PostgreSQL, HTTP Request, IF conditions, Email Send, Data Aggregation

Impact

Reduced customer support calls by proactively notifying affected users before they report issues. Improved technical team response time by providing consolidated affected customer lists every 7 hours. Enhanced customer satisfaction through transparent communication during network outages.

Secure API-Based Data Warehouse Integration System

n8n Multi-Workflow Architecture API Authentication PostgreSQL Webhooks

Challenge

The organization needed a secure, controlled method for external users to input payment data into the data warehouse, with proper authentication, authorization workflows, and admin oversight to prevent unauthorized access.

Solution

Designed and implemented a comprehensive three-workflow system that handles user registration, admin approval, and secure API-based data ingestion with proper authentication and authorization checks.

Technical Implementation

  • Workflow 1 - User Registration: Webhook endpoint accepts user registration (name + email), generates unique User ID and API key, stores in PostgreSQL with initial "inactive" status
  • Workflow 2 - Admin Approval: Automatically sends email notification to admin with Accept/Reject buttons; webhook-triggered approval process updates user status to "authorized" in database upon admin acceptance
  • Workflow 3 - Data Ingestion API: Validates API key and authorization status against database before allowing payment data insertion; implements security checks to prevent unauthorized access
  • Technologies used: n8n webhooks, PostgreSQL database operations, Email nodes with interactive buttons, HTTP Request authentication
  • Security features: API key generation, status-based authorization, admin approval gate, database validation

Impact

Created a secure, scalable system for external data integration with proper access controls. Eliminated manual data entry while maintaining admin oversight. Provided audit trail through database status tracking and reduced unauthorized access risks through multi-layered authentication.
